広告と課金

広告も課金もありません。アクセス解析も使っていません。

ブラウザの中に残すもの

ホールごとの自己ベスト、続きから遊ぶためのラウンドの記録、ランキングの名前と ID を、お使いのブラウザの中（localStorage）に保存します。通信なしで遊べるよう、ゲームのファイルも手元に置きます。ブラウザのデータを消すと、これらも消えます。

ランキングに送るもの

送るのは、ランキングに参加すると決めた人だけです。

  • 自分で決めた名前
  • ブラウザが作った、人を特定できない乱数の ID
  • 合計打数とホールごとの打数
  • 記録を確かめるための、そのラウンドのショット（番手・向き・強さ・回転・球の位置）

名前と打数はランキングでほかの人に見えます。ランキングの画面の「名前を変える」から「ランキングをやめて記録を消す」を選ぶと、名前と記録をサーバーから消せます。ランキングのサーバーは Cloudflare を使っており、回数の制限のために IP アドレスを一時的に扱います。

配信

ゲームは GitHub Pages から配信しています。アクセスの記録は GitHub が扱います。
